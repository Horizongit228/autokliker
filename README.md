# AutoClick X 0.2

Нативный автокликер для Android 7.0+. Интервал 1–60 000 мс. Фактическая скорость ограничена Android: жесты выполняются последовательно. Включите службу в специальных возможностях, установите интервал, переместите мишень и нажмите ▶. ■ прекращает касания, × скрывает панель. APK собирается через GitHub Actions.
