# AutoClick X 0.4

Нативный автокликер для Android 7.0+. Интервал 1–60 000 мс. Фактическая скорость ограничена Android: жесты выполняются последовательно. Включите службу в специальных возможностях, установите интервал, переместите мишень и нажмите ▶. ■ прекращает касания, × скрывает панель. APK собирается через GitHub Actions.

Мишень остаётся видимой при кликах, но не перехватывает касания. Положение сохраняется.

## Подпись APK
Сборка требует секрет репозитория Actions `AUTOCLICK_SIGNING_KEY`: Base64 содержимого постоянного debug.keystore (alias androiddebugkey, стандартный пароль android). Храните резервную копию ключа в защищённом месте. Не публикуйте ключ в репозитории и не меняйте его между обновлениями. SHA-256 сертификата выводится при проверке APK. Если прежний APK подписан другим ключом, Android не позволит обновить его на месте.

Плавающая панель перемещается за ⠿ и сохраняет положение. ⚙ открывает быстрые настройки интервала без перехода в приложение. Открытие настроек или перемещение панели останавливает клики для безопасности.
